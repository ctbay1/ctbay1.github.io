Note 02 · Web app Live at plainspice.com

PlainSpice

Real SPICE, explained in plain words. A beginner-first circuit simulator that runs in the browser, made for first- and second-year students and for my Solved Circuits channel. Draw a circuit or type its netlist, and the answers are written on the drawing.

Engine
ngspice 47, compiled to WebAssembly, in a background worker
Accuracy
Same numbers as desktop ngspice, checked to 6 significant figures
Front end
React 19 and TypeScript; works offline and on a phone
Accessible
WCAG 2.2 AA: keyboard, screen readers, high contrast
Built with
Claude Code as the coding agent, directed by me
Open PlainSpice Source on GitHub
